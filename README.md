
🛍️ #Habitual – E-Commerce Website Design

A visually rich e-commerce UI/UX experience designed in Figma. 
Showcasing smooth interactions.

✨ Features

🎨 Figma Prototyped Design – Built with a focus on balance, contrast, and golden tones.

👤 Onboarding & Signup Flow – Clean and minimal user introduction screens.

💫 Set Your Vibe – Personalized interest-selection animation for tailored experiences.

🛍️ Product Showcase – Animated product cards with add/remove from cart interactions.

💳 Payment Through Scanner – Secure, modern checkout using QR scanning visuals.

🎥 Interactive Demos – Motion-enhanced videos showing key app flows and transitions.
